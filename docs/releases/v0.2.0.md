# Runtime Evolution Workbench 0.2.0

Version 0.2.0 is the first cross-platform technical preview. It saves ordinary Codex Runs locally, keeps observation gaps visible, groups evidence into Issues, and tests one reviewable `AGENTS.md` or `SKILL.md` change in isolated worktrees before a human publishes it.

## Download

- Windows 11 x64: `runtime-evolution-workbench-0.2.0.zip`
- Linux x64 and Apple Silicon macOS: `runtime-evolution-workbench-0.2.0-portable.tar.gz`

Download the matching `.sha256` file from this release, verify it before extraction, and inspect the platform installer. Windows uses `scripts/Install.ps1`; Linux and macOS use `scripts/Install.sh`.

## What changed

- Added ownership-safe install, start, stop, inspection, uninstall, and explicit data deletion on Linux and macOS.
- Added a portable archive that contains the reviewed source, compiled server and web UI, fixed RunCase dependency, and commit identity.
- Added extracted-archive lifecycle gates on hosted Ubuntu and Apple Silicon macOS.
- Made capability publication and rollback resilient to concurrent editor saves and interrupted file moves.
- Added direct validated `agent.run.v1` export and protocol-library downloads.

## Evidence attached

The release workflow publishes checksums, commit-bound manifests, build-provenance attestations, a hosted Windows installation record, and hosted Linux/macOS running and final-absence inspections. Those records prove the packaged lifecycle only.

## Limits

No physical Mac or ordinary user-owned clean machine was tested. No authenticated Codex model Run is attached, so the full failure-to-proposal-to-comparison-to-publish loop remains unproven for this tagged build. The release is a prerelease, uses Codex only, makes no hidden-reasoning claim, and labels every four-cell comparison as single-run evidence.
