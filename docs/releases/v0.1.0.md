# Runtime Evolution Workbench 0.1.0

This technical preview is for individual developers who already use Codex on real repositories and want their own Run history, corrections, and capability-file changes to form a reviewable improvement loop.

## What you can do

- Retain observed and product-managed Runs locally, with redaction and visible observation gaps.
- Turn selected failures or corrections into evidence-backed Issue cards.
- Propose one bounded `AGENTS.md` or `SKILL.md` change without editing the file automatically.
- Compare the original failure and one protection Case across baseline and candidate worktrees.
- Publish only after objective verifier results and explicit approval, then roll back safely or surface a conflict when the file changed later.

## Install

Use the attached `runtime-evolution-workbench-0.1.0.zip` and matching `.sha256` file. Verify the checksum, extract the archive, inspect `scripts/Install.ps1`, and run the installer from a normal Windows Terminal or PowerShell session. The service binds only to `127.0.0.1`; startup is opt-in.

## Evidence attached to this release

- A commit-bound release manifest and SHA-256 checksum.
- GitHub build-provenance attestations for the archive, manifest, and evidence files.
- Sanitized authenticated product-gate evidence for the complete failure-to-proposal-to-comparison-to-publish-to-safe-rollback closure.
- Sanitized release-archive installation evidence covering injected install/repair failures, service and Codex plugin registration, preservation, explicit deletion, and final absence.

These files prove the named release gates only. Comparisons are still single-run evidence, Hooks remain best-effort observation, and the product does not read hidden reasoning.

## Preview boundary and removal

Version 0.1 supports Windows 11 and Codex only. It has no cloud sync, team permissions, automatic publication, model training, or support for other Agents. Review `docs/privacy-and-security.md`, `docs/installation.md`, and `docs/acceptance.md` before using it on a sensitive repository.

Run `scripts/Uninstall.ps1` to remove the service registration, Codex plugin, marketplace entry, and optional Startup shortcut while preserving Run data. Use `-DeleteData` only as a separate explicit choice, then run `scripts/Inspect-Installation.ps1 -RequireAbsent -RequireNoData` for machine-readable zero-residue proof.
