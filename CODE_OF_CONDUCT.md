# Code of conduct

This project is built around evidence, clear boundaries, and respect for the people whose work is being examined.

Participants must be constructive, specific, and respectful; separate criticism of a claim or change from criticism of a person; protect private Run data and credentials; disclose conflicts of interest; and avoid harassment, discrimination, threats, doxxing, or sustained disruption.

Maintainers may edit or remove content and restrict participation when behavior threatens people, privacy, security, or the project's ability to work. Security incidents should be reported through the private process in `SECURITY.md`, not litigated in public threads.

Enforcement decisions should state the violated behavior and the action taken without exposing a reporter's private information. Anyone asked to stop harmful behavior is expected to comply immediately.
