# Support

Use GitHub Discussions for usage questions once enabled and GitHub Issues for reproducible bugs or narrowly scoped feature requests. Read `docs/troubleshooting.md` first.

A useful bug report includes the product commit, Windows/Node/Codex versions, whether the Run was observed or managed, exact observation gaps, the smallest synthetic reproduction, and relevant redacted service logs. Never attach a session token, private Run export, credential, or proprietary repository content.

The 0.1 technical preview has no commercial support or uptime SLA.
